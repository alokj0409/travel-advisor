## Modifications by Alok Jha

The 2026 rewrite by [alokj0409](https://github.com/alokj0409) includes:

- migration from Create React App and React 17 to Vite and React 19
- replacement of Google Maps with Leaflet and OpenStreetMap
- replacement of RapidAPI integrations with Nominatim and Overpass
- a new responsive visual system and component implementation
- location search, geolocation, favorites, filtering, and map/list synchronization
- loading, empty, fallback, and error states
- accessibility, dark-theme, lint, test, CI, and documentation improvements

OpenStreetMap data is available under the Open Data Commons Open Database License. Map attribution is rendered inside the application.
